NextCloud - это клиент под Windows и Linux для одноименного сетевого хранилища. И там, и там он синхронизирует директории, но под Windows у него есть еще один режим работы. Вместо синронизации он создает виртуальные файлы - ссылки, которые синхронизируются выборочно при чтении и записи. Приложение Mail.ru, к слову, только так и работает. С одно стороны, это хорошо - если хранилище большое, незачем его полностью синхронизировать (в процессе можно даже сбрасывать кэш и еще больше освобождать место). А вот с другой... Мало того, что теряется сам фактор дублирования и все зависит от облака, так еще и NextCloud переиспользует функции встроенного в Windows OneDrive. И если синхронизация по каким-то причинам сломалась, локальный файлы блокируются и их невозможно даже удалить. 

Все, что я думаю о OneDrive, Windows и Microsoft с целом оставим в стороне и займемся решением этой конкретной проблемы.

1. Отключаем драйверы виртуальных файлов (в реестре, от администратора):

```
reg add "HKLM\System\CurrentControlSet\Services\CldFlt" /v Start /t REG_DWORD /d 4 /f
```

2. Перегружаемся.
3. Удаляем файлы синхронизации (на вский случай еще и отключив их в клиенте, чтобы файлы в облеке не пострадали).
4. Восстанавливаем настройки, чтобы все снова заработало:

```
reg add "HKLM\System\CurrentControlSet\Services\CldFlt" /v Start /t REG_DWORD /d 2 /f
```

5. Cнова перегружаемся.
6. Восстанавливаем синхронизацию.
